# Design Guidelines

This document outlines the color palette and font style standards that should be followed across all pages of the MiHi Entertainment website.

## Color Palette

### Primary Colors

#### Color 1: Dark Gray/Black
- **HEX:** `#1F1F1F`
- **RGB:** `31 | 31 | 31`
- **CMYK:** `72 | 66 | 65 | 75`
- **Usage:** Primary background color, dark text elements

#### Color 2: Red/Coral
- **HEX:** `#FF4F4F`
- **RGB:** `255 | 79 | 79`
- **CMYK:** `0 | 84 | 66 | 0`
- **Usage:** Accent color, call-to-action buttons, highlights

#### Color 3: Cyan/Turquoise
- **HEX:** `#18F1E1`
- **RGB:** `24 | 241 | 225`
- **CMYK:** `55 | 0 | 24 | 0`
- **Usage:** Secondary accent color, interactive elements, highlights

## Font Style

### Typography

- **Body Text:** Azo Sans
- **Headers:** Azo Sans Uber

### Usage Guidelines

- Use **Azo Sans** for all body text, paragraphs, and general content
- Use **Azo Sans Uber** for all headings (H1, H2, H3, etc.) and header elements

---

## Implementation Notes

When implementing these design guidelines:

1. Ensure consistent color usage across all pages
2. Maintain proper contrast ratios for accessibility
3. Use the specified fonts consistently throughout the site
4. Reference this document when creating new pages or components
